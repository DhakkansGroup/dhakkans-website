How Incognito & Visitors Sync 100% Free on GitHub Pages

  1. Hosted for Free on GitHub Pages: All visitors (including Incognito tabs and mobile users) automatically fetch live data directly from data/db.json in your GitHub repository with zero server, zero tokens, and zero usage limits!
  2. Direct 1-Click Commit (Recommended): Generate a free GitHub Token at github.com/settings/tokens/new with repo permission, paste it in the box above, and clicking "Commit & Push to GitHub" immediately writes your latest updates directly into your repository!
  3. Manual File Upload Option: Click "Download db.json" and drag-and-drop the file into the data/ folder in your GitHub repository.
100% Free & Unlimited: No third-party subscriptions, no trial periods, and no quotas. All website data is fully owned by you on GitHub!
